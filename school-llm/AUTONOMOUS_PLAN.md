# School-LLM — Автономный план (пробить C 73 → 85+)

> Работаем ЗДЕСЬ, в slovo-llm. История/результаты: `RESULTS_HISTORY.md`.
> Условия ЛУЧШЕ контеста: **нет лимита попыток, нет серверного судьи, нет смены правил** → безлимитная бесплатная итерация.
> Цель: 85+ (Гордеева доказала с того же 73). Рычаг: knowledge-gap (Qwen3-8B фабрикует рус.школу).

## 0. КОРНЕВОЙ фикс
Killer прошлого = **слепота** (нет дешёвого судьи → каждая идея = серверная попытка вслепую) + выгоревший бюджет. **Лекарство = БЕСПЛАТНАЯ локальная петля валидации.** Проверяем каждую идею за $0.

## 1. Судья — БЕСПЛАТНАЯ модель по API (у нас уже есть!)
**Laguna (Poolside)** — в slovo-llm уже развёрнута:
- **Локально через Ollama:** `localhost:11434` (контейнер `ollama-laguna`, OpenAI-совместимый `/v1/chat/completions`) — **$0**.
- ИЛИ **Poolside cloud API** по `POOLSIDE_API_KEY` (в `.env`).
- **Кросс-семейство:** Laguna ≠ Qwen (наши solver'ы) → **честный судья** (нет self-preference bias). ✅

**Задача судьи:** `вопрос + gold + наш_ответ → correctness 0-100`. Судить проще чем генерить → Laguna справится для РАНЖИРОВАНИЯ конфигов (её «good draft» уровень тут ок).

**Опционально (кросс-проверка / панель):** локальные Gemma-2-9B / Mistral-Nemo-12B (тоже ≠ Qwen, ~6-8GB 4bit) — но НЕ одновременно с laguna на 16GB (последовательно). Laguna через API не грузит нашу карту под solver → удобно.

**Внимание (co-agent):** laguna в slovo-llm шарится с slovo-backend. Перед тяжёлым прогоном — проверить `~/.claude/AGENT-STATUS.md`, не рвать живые запросы (см. slovo-llm CLAUDE.md протокол).

## 2. Langfuse-судья (визуализация, $0)
1. Судья = laguna (Ollama localhost:11434, OpenAI-совместимый).
2. Langfuse **LLM-as-a-judge evaluator** → `base_url` = laguna endpoint → **$0**.
3. Скоры → дашборды по конфигам/предметам. Langfuse уже развёрнут локально.

## 3. Калибровка судьи (MULTI-anchor — make-or-break)
Калибруем на ВСЕХ известных серверных баллах. **Главный тест = РАНЖИРОВАНИЕ:** судья должен выстроить 73 > 70.3 > 68.4 > 66.4 > 66.2 > 32.3. Порядок верный → судья валиден. Потом фит local→server.

**Якоря + статус данных (в `ML/C_school_llm/work/`):**
| Конфиг | Сервер | Данные |
|---|---|---|
| plain-8B | **73** ⭐ | ⚠️ только срезы 200 → **перегенерить** (веса `weights_8b_awq` есть) |
| T-lite | 70.3 | ⚠️ → перегенерить (веса `weights_tlite_bnb4bit` есть) |
| 14B v7conc | 68.4 | ✅ `q3_14b_v7conc_valid1000.json` |
| genrag | 66.4 | ✅ `gen_rag_1000.json` |
| plain2 | 66.2 | ✅ `base_plain2_valid1000.json` |

→ 4 готовы + 2 перегенерить = **6 точек на 32-73.**

**Бонус — per-subject:** на 8B-73 судья должен показать литература/русский НИЗКО (фабрикация), математика ВЫСОКО. Если видит knowledge-gap → поймает улучшение. Валидирует что судья ловит ось где нас обошли.
